# Contributing

1. Create a focused branch from `main`.
2. Make one logical change.
3. Run local validation.
4. Update documentation and the changelog.
5. Open a pull request.
6. Merge only after required checks and review.

## Branches

`feature/`, `fix/`, `docs/`, `chore/`, and `release/`.

## Pull-request expectations

- No secrets
- No generated build output
- No mutable image tags for promoted environments
- Documentation updated
- Security impact described
- Rollback path documented
