# Enterprise AKS GitOps Platform

Repository 1 provisions Azure and AKS. Repository 2 demonstrates secure application packaging, Kubernetes controls, GitOps delivery, and operations.

## Current release

v1.3.0 adds:

- Argo CD AppProject
- ApplicationSet-generated Dev, QA, and Production Applications
- Development auto-sync and self-healing
- Manual QA and Production synchronization
- GitOps environment image values
- Adjacent immutable-digest promotion
- Drift and rollback procedures
- Bootstrap and validation automation
