# v1.2.0 Interview Story

## Summary

“I packaged the secure FastAPI workload as one reusable Helm chart rather than maintaining separate Kubernetes manifests for each environment.”

## Points to explain

- The same templates serve Dev, QA, and Production.
- Values files express capacity and availability differences.
- Probes map directly to the endpoints implemented in v1.1.0.
- Security contexts enforce the same non-root assumptions as the Docker image.
- HPA handles demand changes while the PDB protects voluntary disruption.
- NetworkPolicy provides pod-level traffic isolation.
- Production uses stronger capacity and disruption settings.
- CI renders and schema-validates every environment before merge.
- The chart accepts an immutable digest so Argo CD can promote the same artifact in v1.3.0.

## Honest boundary

The chart is validated and packageable, but this release does not claim a live AKS installation. Argo CD and actual environment reconciliation begin in v1.3.0.
