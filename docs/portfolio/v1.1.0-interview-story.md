# v1.1.0 Interview Story

## Summary

“I created a small FastAPI service specifically to demonstrate how I prepare an application for Kubernetes rather than focusing only on infrastructure.”

## Points to explain

- Health endpoints map cleanly to Kubernetes probes.
- Environment configuration is validated at startup.
- The app uses structured stdout logging for container log collection.
- Request IDs support correlation across ingress, application, and telemetry.
- Production disables interactive API documentation.
- The image uses a multi-stage build and non-root user.
- CI tests Python 3.12 and 3.14.
- The running container is smoke tested before security scanning.
- Trivy blocks serious vulnerabilities and generates an SBOM.

## Honest boundary

The service is not deployed to AKS yet. Helm packaging and Kubernetes deployment begin in v1.2.0.
