# v2.0.0 Interview Story

“I built an end-to-end AKS delivery platform rather than a collection of YAML files. Development uses fast automatic GitOps feedback, QA uses Argo Rollouts with Prometheus analysis, and Production uses immutable digest promotion with KEDA scaling. Workload Identity removes static Azure credentials, Key Vault CSI mounts secrets without Kubernetes Secret synchronization, OpenTelemetry provides SLO signals, and the release workflow produces a signed image and SBOM. Kyverno begins in audit mode so policy can be introduced safely.”
